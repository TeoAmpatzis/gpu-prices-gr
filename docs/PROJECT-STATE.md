# Κατάσταση του BuildDraft.gr
Τελευταία ενημέρωση: 2026-10-11
Ενημερώνεται μόνο με εντολή του Teo. Αυτό είναι το κύριο αρχείο κατάστασης· αν διαφωνεί με άλλο αρχείο, ισχύει αυτό, και το άλλο σημειώνεται ως παλιό.

## Κανόνες ισχύουν τώρα
1. Κανένα commit ή push στο main, χωρίς νεότερη οδηγία.
2. Το v1 δεν αλλάζει. Καμία δουλειά μόνο για v1.
3. Κανένα νέο πεδίο δεδομένων. Το v2 χτίζεται με τα δεδομένα που υπάρχουν. Εξαίρεση που εγκρίθηκε: ο πίνακας «επίσημη ταχύτητα μνήμης ανά οικογένεια επεξεργαστή» του κανόνα 25 (βλ. Εκκρεμότητες).
4. Πριν από κάθε βήμα: σχέδιο δύο γραμμών και έγκριση. Κανένα επόμενο βήμα πριν εγκριθεί το προηγούμενο.
5. Commit μόνο τοπικά στο v2. Ταυτότητα: TeoAmpatzis <189219701+TeoAmpatzis@users.noreply.github.com>. **Χωρίς γραμμή Co-Authored-By ή άλλη αναφορά στον Claude** στα commits (το credit θα δοθεί από τον Teo όταν τελειώσει το site).
6. **Κανένα push του v2 στο GitHub** (ούτε στο branch v2) μέχρι την κυκλοφορία (βλ. «Σχέδιο κυκλοφορίας»).
7. Μόνιμοι κανόνες UI: κάθε κείμενο σε ελληνικά και αγγλικά (`Text = {el, en}`). v2 μόνο σκούρο θέμα. Κάθε εξάρτηση Python με άνω όριο έκδοσης.
8. Ό,τι οδηγεί σε push, διαγραφή ή μη αναστρέψιμη ενέργεια: επιβεβαίωση πρώτα.
9. Μην ακυρώνεις και μην ξανατρέχεις GitHub Actions runs χωρίς ερώτηση.
10. Skroutz: μπλοκάρεται από Cloudflare σε κάθε run. Χωρίς νέες σελίδες Skroutz μέχρι να γίνει έρευνα (backlog #7).

## Σχέδιο κυκλοφορίας (απόφαση 11/10)
1. Το v2 χτίζεται και ελέγχεται ολόκληρο τοπικά: frontend και backend (scraper, δεδομένα, έλεγχοι).
2. Μέχρι τότε το v1 μένει όπως είναι στο GitHub και στο Vercel.
3. Όταν το v2 είναι έτοιμο και λειτουργικό: το v1 βγαίνει από το GitHub και το Vercel, και ανεβαίνει το v2. Ο τρόπος (π.χ. αντικατάσταση του main ή νέο repo) αποφασίζεται τότε, με επιβεβαίωση του Teo πριν από κάθε βήμα.
4. Το v1 μένει μόνο τοπικά στον υπολογιστή του Teo (`Desktop/PROJECTS/Gpu price comparison`).
