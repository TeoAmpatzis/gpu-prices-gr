Αυτό είναι το κύριο αρχείο κατάστασης. Αν διαφωνεί με άλλο αρχείο, ισχύει αυτό. Η προηγούμενη μορφή (17/10, εποχή πριν από την κυκλοφορία του v2, με όλο το ιστορικό αποφάσεων) είναι στο `docs/archive/PROJECT-STATE-2026-10-17.md`.

## Τι είναι live
- Το **v2 είναι το `main`** (`package.json` έκδοση 2.0.0) και είναι live στο https://gpu-prices-gr.vercel.app. Κάθε push στο `main` κάνει deploy στο Vercel (Hobby). Το v1 υπάρχει μόνο στα παλιά commits.
- Repo: `TeoAmpatzis/gpu-prices-gr` (δημόσιο). Φωτογραφίες προϊόντων: `TeoAmpatzis/builddraft-images` (δημόσιο, GitHub Pages, σερβίρονται από το `/img/`).

- Οθόνες (monitors): live από 2026-11-11. Οι φωτογραφίες τους κατεβαίνουν από το job του `builddraft-images` (πρώτο run 2026-11-11).

## Πώς ενημερώνονται τα δεδομένα
| Workflow | Τι κάνει | Πότε |
| --- | --- | --- |
| `scrape.yml` | Skroutz, μέσα από Cloudflare WARP (proxy) | ξυπνά κάθε 4 ώρες· μια πύλη αφήνει να τρέξει μόνο όταν τα δεδομένα του Skroutz είναι παλιότερα από 11 ώρες (περίπου 2 runs τη μέρα) |
| `scrape-shops.yml` | BestPrice, Snif, Shopflix, e-shop.gr | `43 */6 * * *` |
| `history.yml` | εισαγωγή ιστορικού τιμών του Skroutz | **σε παύση από 2026-11-09** (μόνο με το χέρι, για επαναφορά ιστορικού) |
| `images.yml` (στο `builddraft-images`) | φωτογραφίες για μοντέλα που δεν έχουν | `50 */6 * * *` |

Τα workflows γράφουν το `public/data/` και κάνουν commit στο `main`. Το build του Vercel παράγει από αυτά τα αρχεία του site και αρνείται να δημοσιεύσει σπασμένα δεδομένα (`checkData`).

## Κανόνες που ισχύουν τώρα
1. Push στο `main` = δημοσίευση. Πριν από κάθε push: `npm run check` και `npm run e2e` πράσινα, και ρητό «ναι» του Teo.
2. Ό,τι οδηγεί σε push, διαγραφή ή μη αναστρέψιμη ενέργεια: επιβεβαίωση πρώτα. Ποτέ force push, ποτέ επανεγγραφή του `main`.
3. Τα `public/data/**`, `scraper/**` και `.github/workflows/**` αλλάζουν μόνο με σχέδιο που ενέκρινε ο Teo. Τα δεδομένα δεν γίνονται push από τον υπολογιστή, εκτός αν το ζητήσει ρητά ο Teo για συγκεκριμένη αλλαγή (έγινε μία φορά, 2026-11-11, για τις οθόνες).
4. Μην ακυρώνεις και μην ξανατρέχεις GitHub Actions runs χωρίς ερώτηση.
5. Commits: ταυτότητα `TeoAmpatzis <189219701+TeoAmpatzis@users.noreply.github.com>`, conventional commits, **χωρίς γραμμή Co-Authored-By ή άλλη αναφορά σε AI**.
6. Κόστος 0: μόνο δωρεάν υπηρεσίες.
7. Εξαρτήσεις Python με ακριβείς εκδόσεις (`scraper/requirements.txt`)· τα GitHub Actions με commit SHA. Αλλάζουν επίτηδες, μετά από τοπικό run.
8. Όριο μεγέθους ανά σελίδα στην πρώτη φόρτωση: JS έως 110 KB και δεδομένα έως 300 KB gzip. CLS 0.
9. Τιμές και προδιαγραφές μόνο από πραγματικά δεδομένα ή επίσημες σελίδες, ποτέ από μνήμη.

Οι κανόνες της εποχής πριν από την κυκλοφορία («κανένα push του v2», «το v1 δεν αλλάζει», «commit μόνο τοπικά στο v2») δεν ισχύουν πια· είναι στο αρχείο του αρχείου.

## Έλεγχοι
- `npm run check` = typecheck → lint → unit tests (Vitest) → build με έλεγχο δεδομένων.
- `npm run e2e` = Playwright (Chromium), χτίζει και σερβίρει το `dist` στη θύρα 4174. Μόνο ένας φάκελος εργασίας τη φορά.
- Python, χωρίς δίκτυο: `venv/Scripts/python scripts/checks/test_*.py`.
- Ζωντανό site: `node scripts/checks/site-check.mjs`, `node scripts/checks/freshness.mjs` (αποτυγχάνει όταν μια πηγή είναι παλιότερη από 30 ώρες).

## Τι άλλαξε 2026-11-10 και 2026-11-11 (έλεγχος συστήματος)
Αναφορές: `docs/audits/full-system-audit/` (13 αρχεία, σειρά διορθώσεων στο `12-REMEDIATION-ROADMAP.md`).
- Εκπτώσεις: κανόνας διαμέσου 30 ημερών, όριο 7% (οι εκπτώσεις ακριβώς 7% εμφανίζονται)· η αρχική σελίδα χρησιμοποιεί τον ίδιο κανόνα με τα σήματα και αφήνει έξω πτώσεις πάνω από 60%.
- Αυτόματο build: η προτίμηση dual-channel μνήμης ισχύει μόνο μέχρι +15% στην τιμή.
- Ασφάλεια: κεφαλίδες ασφαλείας και Content-Security-Policy στο `vercel.json` (τα hashes των inline scripts του `index.html` ελέγχονται από τεστ)· ο dev server δεν είναι ορατός στο δίκτυο χωρίς `DEV_HOST=1`.
- Scraper: μέγεθος μνήμης κάρτας γραφικών από τον κωδικό προϊόντος (όχι «RTX 5070 16GB»)· ένα κατεστραμμένο αρχείο δεδομένων σταματά το run· τα αρχεία γράφονται ολόκληρα (`write_atomic`).
- Οθόνες: ταυτότητα μοντέλου, 140 διορθώσεις ρυθμού ανανέωσης από σελίδες κατασκευαστών (`scraper/overrides.json`), υποψήφιες φωτογραφίες.
- Κάθε διεύθυνση έχει δικό της αρχείο HTML με τίτλο, περιγραφή, canonical και προεπισκόπηση (`src/lib/staticPages.ts`, γράφεται στο build)· οι σελίδες προϊόντων που δεν πωλούνται πια έχουν `noindex`.
- Σελίδες πληροφοριών, αναζήτηση, σύγκριση: χωρίς μετατόπιση περιεχομένου (CLS 0).
- Διαγράφηκε το παλιό, αχρησιμοποίητο UI λίστας (`ModelTable`, `ModelRow`, `Pagination`, `SortHelp` στο `src/components/`).
